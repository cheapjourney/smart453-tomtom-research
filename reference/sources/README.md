# Sources

- [`sources.md`](sources.md) — source-quality register with class, availability,
  access status, and publication decision.
- `../data/sources.csv` — machine-readable version.

Classes: **A** manufacturer/regulator, **B** original artifact/source code,
**C** own observation/report, **D** community report, **E** unverified/unavailable.

An `internal` source is listed for provenance only; its content and locator are not
published. A `gated` or `dead` source is not treated as a confirmed fact.
